# Code of Conduct

Be kind and be specific. Disagree with ideas, not people. Assume good faith, and explain your
reasoning so others can check it. Harassment, personal attacks, and discrimination are not
acceptable here.

Maintainers may edit, hide, or remove contributions that break these rules and may block repeat
offenders. To raise a concern privately, use the repository's Security tab
("Report a vulnerability") and state in the report that it is a conduct matter.
